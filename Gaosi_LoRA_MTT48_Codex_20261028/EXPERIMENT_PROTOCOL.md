# Gaosi-LoRA L1｜MTT S4000 48GB：学习型适配器去噪实验

**2026-10-28｜给 Codex 的自包含研究协议。状态：方案与小张量参考实现；未在用户主机训练。**

## 0. 执行摘要与本轮替代关系

用户提供 AutoDL MTT S4000 48GB，有两个月免费资源，由 Codex 执行。先复用配套 MUSA 环境，跑通真实模型，再连续完成核心实验。不要自动购买算力、升级宿主驱动或扩展付费 API。

本版取代旧文件中“禁止 LoRA、必须全参数更新”的限制，也取代旧环境说明的“仅配置、之后永久停下”安排：用户把此包交给你并授权执行后，可在既有资源/额度内完成本包 core。旧的全参数结果保留，不把它们与新的 LoRA 结果混算。

**研究对象没变：真正学习的是去噪/恢复规则 φ，不是只给普通 LoRA 训练器换个名字。**

核心问题：在不对基座进行梯度更新的条件下，扰动已承载知识的 LoRA 适配器，再通过数据条件的 φ 恢复或更新，能否改善新学习—旧能力保留，并在持续更新中继续有效？

这轮首先检验**适配子空间上的条件恢复**，不是全参数 iid 噪声的等价实现。全参数研究并非没有道理；LoRA减少训练状态，让更强基座与更充分的机制验证变得可行，同时也引入低秩限制。成功或失败都要按这个范围解释。[R1]

## 1. 三套参数和两种噪声必须分开

- `W0`：预训练基座；O1/O2/O3全程固定，不求权重梯度，但保留穿过其运算的激活梯度。
- `psi={A_l,B_l}`：模型工作状态中的适配器；在一次恢复内由 φ 或基线修改。
- `phi`：跨元训练 episode 学到的更新网络；正式适应/持续学习时固定。

对一个线性层：

    W_eff = W0 + s B A
    A: [r, in]，B: [out, r]，s=alpha/r

默认 `r=32, alpha=32, s=1, dropout=0, bias=none`。指定7类模块：`q_proj,k_proj,v_proj,o_proj,gate_proj,up_proj,down_proj`。不更新 lm_head、embedding、norm、原bias；不把这种范围叫“全部预训练参数加噪”。Base 使用普通续写问答格式，不强加聊天模板。[R2]

一个元训练 episode：取父适配器副本→在这个副本加一次噪声→用同任务 support 与 retain 数据恢复 K 步→在合法 meta-query 上评价→只更新 φ→丢弃本次适配器和内层状态。φ在episode内数值固定，但可求其梯度。

正式应用：冻结φ，计算适配器 support 梯度作为条件，更新ψ，输出W0+ψ。**冻结φ不意味着恢复过程免反向传播。**最后模型问答时不再调用φ或再次加噪。

`q_train`与`q_apply`单独配置；训练受噪并不要求每次应用重新受噪。周期扰动属于独立持续学习分支。

损失的三个量均用同一评价集：

    injected = L(noisy)-L(clean)
    recovered = L(noisy)-L(output)
    residual = L(output)-L(clean) = injected-recovered

初始损伤仅诊断；不单独罚给φ。中间允许受损；终点残留必须报告。正式主目标只评价完整K步终点，不默认每2步都惩罚未恢复能力；梯度截断长度另外标明。[E1]

## 2. 硬件、模型与真实内存账

**主模型 Qwen2.5-3B Base；7B Base 早期真实加载/学习探针，随后关键规模复核；1.5B仅用于高阶后端诊断，不承担主结论。** 不因为3B未胜出就取消7B。模型revision和许可记录到config；不擅自接受受限条款。[R6,R7]

默认 3B、rank32、7类矩阵共约59,867,136个适配器参数；7B对应80,740,352。由官方 config 中实际矩阵形状计算，生产代码需对实例化模型重新计数。[R6,R7]

| 项目（十进制GB，静态计算） | 3B/r32/all7 | 7B/r32/all7 |
|---|---:|---:|
| 冻结BF16基座 | 6.18 | 15.22 |
| 适配器FP32参数+梯度+mD+mR+v | 1.197 | 1.615 |

**不含激活、logits、高阶图、临时buffer及PEFT缓存，不能当峰值。** 低秩减少参数梯度/状态，并没有消除穿过Transformer的计算与激活。48GB应先承接3B主体与7B短序列验证；H2是否可用看实际算子与峰值，不凭显存数字承诺。

系统RAM推荐128GB，64GB可做不合并的常规路线；O4的7B FP32基座母本约30.44GB，连同加载/序列化需额外余量。磁盘建议至少150–250GB实际可用，优先存adapter/φ和少量父基座，别每个恢复点存完整LLM。

默认序列512、microbatch1，每路support累积至512有效token；优先完整答案。真实后端测好后提高批量或序列，不把截掉答案当省算力。

## 3. 四种LoRA组织：全部做，不做笛卡尔积

### O1｜共享、可继续更新的单LoRA（主线）

一套rank32适配器承载历次新知识，A、B均可更新。独立元episode重置到父适配器；持续学习轮次间不重置。它最直接检验“已学知识受损→数据条件恢复”。

### O2｜固定输入子空间，只更新B

从与O1**功能相同**的父适配器开始，统一QR坐标化后固定A，只更新B。主噪声只破坏B对应的有效系数，固定A不是隐形的受损参数。rank32、推理容量与O1相同，但可训练参数更少，成本和控制自由度分别报告。

这是fixed-A/B-only对照，不自动等同于原论文LoRA-FA（其优化细节可能不同）。如果O2成为最佳，补官方LoRA-FA或其等预算移植再谈超越；不能以它受限而否定O1/O3。[R2]

### O3｜双分支、分阶段可塑性（总rank仍32）

    W_eff = W0 + B_stable A_stable + B_plastic A_plastic
    rank_stable=16, rank_plastic=16, 两支scale=1

起点从同一canonical rank32父LoRA按固定随机列划分为16+16，拼接/求和严格等价。日间学新任务只更新plastic；夜间恢复时两支都可更新，并在noise组**两支都扰动**。不能把旧知识放到一支永远保护的干净旁路，还称去噪器恢复了它。

主版本不在每轮重置plastic，不增加新分支、不使用任务ID路由；推理两支始终同时激活。稳定/可塑是更新日程，不是永远冻结的记忆。每轮边界统一canonicalize并重置内层状态，所有配对组同政策。

单次独立恢复与O1可能数学上很接近；其主要组织差别在连续学习的日/夜日程，不把静态双分支分数变化自动归因于新记忆结构。

### O4｜本轮适配器去噪后合并，下一轮重启

每轮开始有已合并的基座Wt；新建rank32零输出LoRA；先正常学习新数据，形成**非零**adapter，再进行本轮clean/noise恢复；结束后将其低秩增量以FP32累积合入持久基座母本，重置新LoRA与内层优化器，进入下一轮。

W0不再是跨轮永久不变的基座，但每个内层训练阶段仍不对它求参数梯度。不能用每轮重新从BF16读取的“母本”反复小步合并。

O4的元适配父状态这样构造：从meta历史父adapter合入一个允许变化的W_hist，再在这个W_hist上用另一套meta新增绑定训练本轮非零adapter。纯恢复只把“本轮adapter已学信息”当恢复目标；合入W_hist的历史事实作为保留。新的适应episode换一批未见meta绑定。构建这些父状态的费用独立计入，不藏在512步φ适配内。

这是merge-and-restart的简化实验，与ReLoRA有直接联系，但不包含其全部训练日程/优化器处理，不能冒充完整复现。[R3]

O4累计的有效改变量rank可以随轮数增长；它不是与O1完全相同的固定rank容量。主噪声只重整本轮新adapter，不会破坏已经合入Wt的全部旧知识。**O4不承担“删除已合并旧知识”的主要证据**；本轮尚未合并的新增知识可以另测选择性。

### 每种组织都配自己的基线

各自比较clean-Adam、noise-Adam、clean-φ、noise-φ，日程、可训练参数集合、回放容量与合并规则相同。不能用O3的φ去打O1的Adam，再把所有收益归因于φ。

跨组织同rank不等于同可训练参数、同计算或同累计rank，均分别记账。先各一条8轮轨迹，再复现最有信息的两种组织；不是四种都做全部参数网格。

## 4. rank、模块覆盖与LoRA变体的有限筛选

先用普通Adam、一个开发种子、两个任务（事实/可测规则），比较5个配置：

1. all7 / r16；2. all7 / r32（默认）；3. all7 / r64；4. attention4 / r32；5. q,v / r32。

各跑足以看学习曲线的16/64/128步；确实未收敛时统一延长至256，最多一次512。学习率 `{3e-5,1e-4,3e-4}` 先在默认配置选，再给候选最多一个相邻补点。LoRA的学习率不照搬全参数的1e-5作为唯一选择。

这是**可学性/代价筛选，不是所有配置都训练φ**。r变化时默认alpha=r令scale=1；模块不同导致参数量不同，报告真实参数量，不能声称纯位置因果。若窄模块明显欠容量，主要结论仍用all7。

rank32在联合学习中够用则保留；明显不足而r64有效时，在φ正式训练前冻结改用r64。最终rank/module设置在φ正式训练前冻结；之后换rank或覆盖范围先称迁移诊断，不能以域外负结果判架构失败。另以rsLoRA同预算开发一个对照，`scale=alpha/sqrt(r)`，必须记录实际scale和相同调参机会，不把放大更新量称新机制。[R2,R4]

**低成本强基线**：固定A/B不同学习率，B/A倍率 `{1,4,16}` 开发选择；这与LoRA+思想相关，采用原式时才标复现，否则称factor-LR baseline。[R5] φ的优势不能只是替代一个明显欠调的A/B步长比例。

DoRA不是首批必需：它多出幅度参数和额外算子，会改变噪声对象；只有LoRA主线有明确信号时加一组，不为“多试”展开所有变体。QLoRA也不默认加入，避免量化误差与MUSA专属依赖混入加噪机制。

## 5. 加噪的正确定义：先作用于学过知识的适配器

### 5.1 为什么不能照搬全参数噪声

随机新LoRA常用A随机、B为零，初始增量为零。[R2] 对这样的空adapter谈“弱化已学能力”没有意义。主恢复实验先得到已学会事实且语言正常的父adapter，再扰动。

NEW元任务也主要从非零、已含保留知识的父adapter出发；从空adapter学习只作为scratch基线。零adapter不人为加入按基座尺度设的大噪声来伪造损伤。

主线不破坏冻结基座再只要求LoRA修补。那会将“噪声是否可恢复”和“低秩补偿空间是否够”混在一起。保留一个**小规模base-noise+LoRA repair边界诊断**，但不进入主训练、不代表本轮失败。

### 5.2 N-sub：有效低秩增量中的高斯扰动（主定义）

A的可逆重参数化会改变因子统计而不改变BA；因此不要只按A/B直方图判断噪声大小。

在episode边界、无计算图时：

    A^T = Q R                 # reduced QR，Q^T Q=I
    A_c = Q^T
    B_c = B R^T
    C = s B_c                 # ΔW = C Q^T，与原sBA相同
    sigma = ||C||_F / sqrt(d_out*r)
    C_q = sqrt(1-q)*C + sqrt(q)*sigma*Z,  Z_ij~N(0,1)
    A_work = A_c; B_work = C_q / s

q=0的对照也做相同QR与内层状态重置。QR不截断秩；MUSA不支持时在CPU处理小因子并记搬运成本。固定QR符号，近退化秩需要记录。

由于Q列正交，单支adapter满足 `E||ΔW_q||²_F = ||ΔW||²_F`。这只保持**期望能量**，不保持全部分布、均值/谱结构、能力或语言输出。在完整矩阵坐标中它是低秩相关高斯，不是全基座逐元素iid噪声。推导与数值参考见附录。

O1恢复时A/B都可更新；O2固定A只更新B。O3分别canonicalize两支并各加噪，记录**合成增量**的实际损伤，不能由单支能量保持推出两支总能量也保持。

每次独立恢复只加一次；持续夜间才重复。φ不能读原Z或干净因子坐标。干净函数/噪声可以作元训练监督标签，不是正式还原输入。

### 5.3 N-factor：两因子都加高斯的直接对照

对同样canonicalized的A/B分别做RMS缩放的 `sqrt(1-p)*X + sqrt(p)*RMS(X)*Z`。p和N-sub的q不是同一剂量；BA包含交叉项，不宣称有效权重能量或方差保持。

只在O1、一个父adapter、一个可测损伤档上配对N-sub和N-factor；默认φ在N-sub上训练，因此其N-factor表现先称噪声分布迁移诊断。若要主张某种噪声 本身更优，需给两种分布同预算本地适配，不能让一种域内、一种域外而直接下结论；对照共享实际数据与停止规则。报告参数空间相对扰动、已知知识下降、语言ΔNLL。可按开发功能损伤另匹配一次，不能假定同数值q就是公平。

### 5.4 剂量与缩放控制

q网格 `0,1e-4,3e-4,1e-3,3e-3,.01,.03,.1,.3`；开发集找轻/中两个有可测已知知识弱化、普通完整恢复也可用的档。语言ΔNLL约.05/.20仅定位参考，不要求全部命中。父adapter不同用自己的统计；正式test不选最有利q。

在一个档补 `C_shrink=sqrt(1-q)*C` 的仅收缩对照，必要时另找相近初始功能损伤的收缩系数。再给fixed-update norm匹配一个点。高斯与一般扰动的独特性只有补同方差uniform后才能讨论。

## 6. φ架构与可训练量

复用旧项目正确的元梯度逻辑，但把工作变量从全部θ改为ψ。原0.5B结果只能作为历史，不能算LoRA结果；旧8万参数phi若输入语义变化也不能静默加载。

- **φ-L**：48→256→256→2共享MLP，每个LoRA因子张量独立条件/输出；78,850参数。
- **φ-X**：48→256→256→18，前2输出倍率、后16为context；共享坐标头24→32→1；总83,795参数。

输入沿用旧40维局部梯度/尺度/时间信息，加A/B身份、rank、scale和分支角色等8维。精确定义见NUMERICAL_CONTRACT。网络大小是设计初值，不是证明容量充分。

两路Adam型状态：

    g = gD + wR*gR
    mD = beta1*mD+(1-beta1)*gD
    mR = beta1*mR+(1-beta1)*wR*gR
    v  = beta2*v +(1-beta2)*(gD+wR*gR)^2
    uD = mD_hat/(sqrt(v_hat+1e-16)+1e-8)
    uR = mR_hat/(sqrt(v_hat+1e-16)+1e-8)
    Δψ = -eta*(alphaD*uD+alphaR*uR) + eta*0.1*rms(uD+uR)*e_phi

L没有残差，X按因子坐标有不同残差。倍率`exp(log4*tanh(raw))`；输出头零初始化，倍率1、残差0。未训练φ严格等价于同定义paired-Adam基线；保留标准库Adam强对照，不把ridge差异当贡献。

## 7. 元训练目标、噪声分离与H2

### 7.1 主目标只评价完整恢复终点

    J_K = CE(allowed_task_query; W0,ψ_K)
        + λL [ CE(lang_query;W0,ψ_K)-CE(lang_query;clean)-δL ]_+
        + λR [ CE(keep_query;W0,ψ_K)-CE(keep_query;clean)-δR ]_+

δ默认.10 nats/相应有效token；λ默认1，开发最多.25/1/4。纯恢复的task query只含允许恢复内容；选择性D−不能把目标正确答案梯度偷偷加回。干净参考只作外层基准，不是φ输入。严格生成/候选排名、保留事实与语言NLL分开报告。

`q_train`按0/轻/中均衡（phi_mix）；`phi_clean`全q_train=0，匹配元训练机会。应用各取q_apply=0和非零。因此可区分训练噪声价值与应用噪声价值。没有phi_clean时不声称训练噪声已产生独立收益。

### 7.2 主训练量和课程

每个φ主seed：64个episode×8步已知恢复，随后128×16步恢复/新学习各半，总2560个内层更新、192次phi优化。整episode内φ数值固定；只在episode终点更新。初值 meta lr=3e-4、clip phi norm1；开发可1e-4。每路support初始512有效token，三路成本分别记。

先在O1/all7/r32训练phi-L和phi-X各一个seed17。随后按开发冻结主结构，不在最终test选。末段dev仍显著改善时可一次匹配延长64×16，不把固定2560等同充分训练证明。

组织适配：从同一选定phi快照，为O1/O2/O3/O4分别做64×8=512步、相同机会的短适配；O1也追加。O4使用meta父状态中已合并历史＋本轮非零adapter，不能把未合并父状态冒充。短适配无优势只说明该预算下的组织迁移；关键组织若仍持续改善，给与对应基线同预算延长，不能一口断言不适配。

phi_clean在主组织O1上匹配选定phi_mix的总训练预算（通常2560+512=3072），不扩成所有组织的全矩阵。组织研究默认使用phi_mix，但只能对O1作严格的q_train归因。

### 7.3 真H2而不是两次H1

主候选 `terminal_K_H2_tail`：前K−2步数值运行，固定边界，精确反传最后两步（ψ、mD/mR/v、连续特征状态都参与）。它评价终点，但不是完整K步梯度。H1只反传最后一步；初始损伤不进入额外罚项。

先在极小LoRA模型验证完整2步链式导数，再在真实3B短序列实测MUSA。LoRA减少参数状态，**冻结W0不等于取消穿过W0/激活/attention的高阶依赖**。[R8]

H2后端可用时，phi-L主训练用H2，phi-X同样尝试；如X的坐标路径确实受限，保留L-H2和X-H1，但结构主比较补L-H1，不能把时域与结构混成一个因果效应。

H2失败：修普通数学实现/attention后端，不升级整个系统；明确算子最小复现。可先完成H1全部可用实验，H2标NOT_AVAILABLE_BACKEND，不能说已排除短视。显存不够用重计算/减同时驻留，不偷偷改FO。单纯换80GB也不能解决缺算子；需要NVIDIA补测时提交确切缺口。

精确完整H4/H8只对少量开发轨迹作截断诊断，不启动整套大规模高阶队列；与同K同状态的截断导数比较。原轨迹加权目标仅作后续对照，不默认回来惩罚早期受损。[E1]

## 8. 数据与信息权限

附带 `tools/build_tasks.py` 创建可追踪的合成事实/规则，既有项目数据可在满足相同协议时复用。事实词表与实体绑定可重新生成但固定seed。

父LoRA用普通训练注入，混入通用语言。闭集准确率约85%且严格生成真实可答为可测性参考，不强迫靠过拟合使语言崩溃。先1epoch、检查覆盖，再最多6epoch；必要延长一次说明原因。不同rank/module覆盖可从同数据独立训练父adapter，不能硬截断r64结果当r16的公平父状态。

## 9. 选择性恢复：主要验证O1，必要时O2/O3

模型是 `W0+ψ_all`，目标知识被人为教入ψ，W0本来不知道；另训练`ψ_retain`作为未教目标的适配阶段参考。只关闭adapter会同时丢掉许多非目标新增知识，必须报告这个drop-adapter基线，不能把它当选择性遗忘成功。

正式F固定为final库一个属性的64个绑定，R为其余448；另有实体级小请求用于回流。φ在final父适配器训练之前已经冻结，不把final知识喂回φ训练。

同一受损ψ分别运行：Adam-D+、Adam-D−、phi-D+、phi-D−。

    LD+ = .5*CE(F_support) + .5*CE(R_fact_support)
    LD- = 0                  + .5*CE(R_fact_support)
    两者另加相同 wR*CE(language_support)

F文本不进入D−输入；空F槽为零，不重归一化剩余项，不把R多重复一倍。R曝光、mask、样本流和权重相同。每个语义slot的CE各自按有效监督token求均值；D+的F slot与R slot可各累积512有效token，D−只计算同一R slot，不能因省掉F把R再翻倍。LD的实际token量与language route分别记录，不把复合D默认当只有512 token。采样按绑定轮换再换问法，记录每条恢复轨迹覆盖了多少R；“完整可访问池”但尚未覆盖的短轨迹必须如实标记，正式终点至少覆盖全部预定R绑定一次。所有比较方法用相同支持样本流和终点覆盖机会。保留混合段落中的非目标命题，不教 `something/unrecorded`。

报告clean/noisy/8/16/32/64的F、同实体其他属性、同段R、语言、严格生成和异常输出；完整恢复终点由dev冻结。信息充分的R先测，再给固定25%R子集的资源受限版本。

回流：phi-D−、Adam-D−、ψ_retain各用纯R继续20/80步；另在实体级请求里重教2/8事实，测未重教6条。两个dev冻结lr、相同预算。

**边界：若F本来在不可变W0中存在，纯adapter方法不能把W0中的存储抹掉，最多改变组合模型行为。卸载adapter后原基座知识仍在。** 不可将此研究称为预训练知识的永久/信息论删除。O4已合并的F同理，除非另起明确的基座编辑实验。

## 10. 组织比较与持续学习

先冻结phi，并且在真实有效任务上比较4种组织×4种夜间方法，**各1条8轮先导**。然后对O1及最有信息的一种组织做另外2个独立任务顺序/训练种子确认，不重复所有rank/module网格。

每轮新增32事实，白天普通Adam学习32步；晚间16步同回放/语言恢复。若dev显示欠训练，各配对组统一延长。总回放128条真实绑定，固定预生成reservoir顺序；不使用未来数据，不增长成全历史库。各组测试时都面对全部历史查询，不输入当前任务ID选adapter。

日间状态：O1 A/B全更新；O2只B；O3仅plastic；O4新建零adapter，更新A/B。
夜间状态：O1 A/B；O2只B；O3两支A/B；O4本轮已学非零adapterA/B。噪声作用于这些需要恢复的适配器，不碰冻结基座。O4结束后合并再reset。所有组织分别有自己的Adam基线。

所有组每个day/night边界对所需状态采取同一重置规则；每次canonicalize后必须重置因子坐标系相关moment。每轮记录实际rank、可训练/总adapter参数、累计合并rank界、文件大小、合并舍入与推理开销。O4不能声称累计固定rank，O3不能说两支等于多一倍预算。

第0/4/8轮复制当前模型，用统一的新rank16 scratch adapter在4个未见任务上学习1/4/16步后丢弃副本；基础参考也做同样操作。这个probe刻意给各组相同额外容量，衡量当前表示对**共同新适配器**的后续可学性，不等同于原adapter剩余容量；同时保留各组原生day学习曲线。

8轮不是长期持续学习已解决。有可解释信号后在新顺序延至16或32；不要提高基线lr直到它坏掉。

## 11. 7B规模与真实文本外推

7B最初就做普通LoRA已知能力与噪声恢复，不能等3B胜出才启动。冻结3B训练的φ做8个未见任务：普通LoRA、phi clean/noise；然后选定结构在7B上做64×8=512步本地适配，保存起点与轨迹。冻结失败不代表7B本地方法失败。

若7B成为主要正/负结论，本地元训练继续到与3B可比的充分预算（通常2560），不是拿512对比3072宣布规模优势或失败。大模型/多步缺口分别报告，不自动换更小基座后冒充7B。

合成任务出现清楚机制后，加一个真实文本任务：CLINC150的固定in-scope子任务（开发域与正式域分开，生成原标签、无额外分类头），或用户已有合法等价任务；选择后写入冻结config。来源与原任务设置差异明确，不为每一种组织都再做全数据矩阵。[R11]

本轮RL/完整RSI不在首批长队列。后续需要时奖励更新的仍是φ，不能直接跑普通LoRA-GRPO然后称Gaosi被验证。先取得条件恢复、训练/应用噪声与持续更新的结论。
